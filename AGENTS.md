# Project instructions

- Keep this project focused on native Codex subagents through Responses-compatible endpoints.
- Use Python's standard library; do not add dependencies without a demonstrated need.
- Never commit API keys, local credentials, logs, backups, generated catalogs, or runtime state.
- Preserve the user's existing parent provider, default model, and unrelated Codex settings.
- Run the offline unit suite for code changes and report real API checks separately.
- Project edits do not update an installed adapter automatically.
